# Volnorez CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Go CLI that turns one MP3 into one 1080×1920 MP4 with a circular cover, live waveform, and word-highlighted subtitles from `whisper.cpp`.

**Architecture:** A small Go pipeline validates the request, invokes `ffprobe`, `ffmpeg`, and `whisper-cli` through argument arrays, converts timed words into ASS events, renders a sibling temporary MP4, verifies it, and atomically publishes it. Media work stays in FFmpeg; Go owns orchestration, validation, subtitle construction, cleanup, and errors.

**Tech Stack:** Go 1.24+, standard library, `golang.org/x/image/font/sfnt` v0.44.0, FFmpeg/ffprobe, whisper.cpp `whisper-cli`, ASS/libass, GitHub Actions.

## Global Constraints

- Target macOS and Linux on amd64 and arm64; Windows is outside MVP scope.
- Input is one MP3; output is one MP4 at 1080×1920, constant 30 FPS, H.264 `yuv420p`, AAC stereo 192 kbit/s, with `faststart`.
- Duration must match the selected interval within 0.2 seconds.
- Default layout is a dark background, optional title, small circular cover in the upper third, large centered waveform, and subtitles in the lower safe area.
- The accent color controls the waveform and active subtitle word; default is `#FFD84D`.
- Transcription is local through an installed `whisper-cli`; the model comes from `--model`, then `WHISPER_MODEL`.
- `--language` defaults to `auto`; word timing uses `--max-len 1 --output-json-full`.
- Cover resolution order is `--cover`, then embedded MP3 art, then a pre-transcription error.
- Title resolution order is `--title`, then MP3 title metadata, then no title.
- The binary embeds an open-licensed Noto Sans default font; `--font` accepts a TTF or OTF path.
- Existing output is preserved unless `--force` is set; rendering never writes directly to the final path.
- Child processes must be started without a shell and canceled on `SIGINT`/`SIGTERM`.
- Normal stdout contains only the final path; progress and errors go to stderr.
- `go test ./...` must pass without a Whisper model.

type appDeps struct {
	context func() (context.Context, context.CancelFunc)
	pipelineDeps func(tools.Runner) pipeline.Dependencies
	pipeline func(context.Context, cli.Config, pipeline.Dependencies, io.Writer) (string, error)
}

func defaultAppDeps() appDeps {
	return appDeps{
		context: func() (context.Context, context.CancelFunc) {
			return signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
		},
		pipelineDeps: pipeline.DefaultDependencies,
		pipeline: pipeline.Run,
	}
}

func runWith(args []string, getenv func(string) string, stdout, stderr io.Writer, deps appDeps) int {
	cfg, err := cli.Parse(args, getenv)
	if errors.Is(err, flag.ErrHelp) { io.WriteString(stdout, cli.Usage()); return 0 }
	if err != nil { fmt.Fprintln(stderr, "volnorez:", err); return 2 }

	output, err := deps.pipeline(ctx, cfg, deps.pipelineDeps(runner), stderr)
	if err != nil { fmt.Fprintln(stderr, "volnorez:", err); return pipeline.Code(err) }
	fmt.Fprintln(stdout, output)
	return 0
}
